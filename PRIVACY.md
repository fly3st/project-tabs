# Project Tabs privacy policy

*Last updated: 2 November 2026*

Project Tabs is a Chrome extension that shows your tab groups as projects in a side panel. This policy explains what information it uses and what happens to it.

## The short version

Project Tabs does not collect, send, sell or share any of your data. Everything it keeps stays in your own browser.

## What Project Tabs uses

To do its job, Project Tabs reads the following from Chrome on your device:

- **Tab groups**: each group's name, color and whether it is collapsed.
- **Tabs**: the title and web address (URL) of your open tabs, and which group each belongs to.
- **Tabs on your other devices**: if you use Chrome Sync with "Open tabs" turned on, the titles and addresses of the tabs open on your other signed-in devices, as Chrome already provides them.
- **Site icons**: the small icon of each website, read from Chrome's own icon cache.

Project Tabs never reads the content of the web pages you visit.

## What it stores, and where

Project Tabs saves a library of your projects (each project's name, color, and the titles and addresses of its tabs) so you can reopen projects later. This library is stored with Chrome's extension storage (`chrome.storage.local`) on your computer, in your Chrome profile. A short-lived list linking open groups to saved projects is kept in Chrome's session storage and is cleared when Chrome closes. One display preference (whether you have hidden a tip) is kept in the panel's local storage.

None of this is sent anywhere. Project Tabs has no servers, contains no analytics or tracking code, and makes no network requests of its own.

## Backups

If you choose **Export backup**, Project Tabs creates a JSON file with your projects and Chrome saves it wherever you choose. If you choose **Import backup**, it reads the file you pick. What you do with those files is up to you.

## Sharing

Project Tabs does not share, sell or transfer any information to anyone, and does not use it for advertising, credit decisions or any purpose other than showing and managing your projects.

## Deleting your data

Remove a single project with its trash button in the panel. To delete everything, uninstall Project Tabs from `chrome://extensions`; Chrome deletes the extension's storage when it is removed.

## Changes

If this policy changes, the new version will be published here with a new date.

## Contact

Questions about this policy can be sent through the support link on the Project Tabs page in the Chrome Web Store.
